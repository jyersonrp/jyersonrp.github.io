## ⚡ Características Clave

1. **Núcleo 3D de Visión Artificial (`Three.js` + WebGL)**:
   - Poliedro cristalino neural en suspensión con shaders de escaneo perimetral interactivo.
   - HUD cinemático de visión computacional con bounding boxes reactivos, telemetría de coordenadas y monitor de FPS en tiempo real.
   - Raycasting con respuesta inercial al puntero y estrangulación adaptativa de rendimiento en dispositivos móviles.

2. **Fondo Cósmico Dinámico e Interactivo (*Canvas API Pure Physics*)**:
   - Motor estelar de partículas basado en Canvas API nativo ("Suivez l'étoile") sin dependencias pesadas.
   - Simulación física de campos de atracción/repulsión gravitatoria con el cursor y líneas de conexión de luminiscencia variable según la distancia Euclidiana.
   - Sincronización cromática inmediata con la paleta de color activa.

3. **Command Palette Profesional (`Ctrl + K` / `Cmd + K`)**:
   - Centro de comando flotante con atajos globales de teclado.
   - Búsqueda difusa (*fuzzy matching*) para navegación instantánea por secciones, filtrado en vivo de proyectos, alternancia de idiomas, cambio de temas cromáticos y accesos directos de contacto.
   - Feedback acústico opcional sintetizado mediante Web Audio API.

4. **Barra Superior de Progreso Ultra-Moderna**:
   - Barra de progreso ultra-delgada (2.5px - 3px) con gradiente dinámico reactivo (`--accent-gradient`).
   - Sincronización dual entre `framer-motion` (`useScroll`, `useSpring`) y el motor de desplazamiento cinemático `Lenis`.
   - Punta con micro-indicador de luz cuántica (*photon spark*), resplandor radial difuso y anillo de aura pulsante.

5. **Sistema Bilingüe Integral (Español / Inglés)**:
   - Cambio de idioma instantáneo (`ES` / `EN`) con persistencia local (`localStorage`).
   - Cobertura completa: navegación, biografía técnica, métricas, casos de estudio, timeline educativo/profesional y modal de currículum.

6. **Motor de Paletas Cromáticas & Modo Oscuro / Claro**:
   - 3 temas de acento vibrantes:
     * **Cyber Emerald**: `#2EE6A0` & `#00F0FF` (Acento cian y esmeralda cuántica).
     * **Neon Violet**: `#A855F7` & `#38BDF8` (Acento violeta ultravioleta y azul cielo).
     * **Solar Amber**: `#F59E0B` & `#F97316` (Acento ámbar cálido y fuego solar).
   - Soporte para modo **Dark** (Obsidian `#070709`) y modo **Light** (Slate `#F8FAFC`).

7. **Suite de Seguridad & Hardening (15/15 Tests Pasados)**:
   - Sanitización rigurosa de entradas contra XSS (scripts, iframes, evasión de etiquetas anidadas, esquemas `javascript:`/`data:`).
   - Prevención contra CRLF / Email Header Injection y neutralización de null-bytes.
   - Límite de tasa (*rate-limiting*) en memoria para formularios de contacto con protección anti-abuso.
   - Ensamblado seguro de correo electrónico con ofuscación anti-scraping (el correo no existe como texto plano en el archivo de utilidades).
   - Escaneo estático en CI para prevenir *reverse tabnabbing* (`rel="noopener noreferrer"` en todos los hipervínculos externos).
   - Cabeceras estrictas de **Content Security Policy (CSP)** y **Permissions-Policy** integradas en el documento base.

## 🚀 Proyectos Estrella Destacados

### 1. Smart NVR con IA & Visión por Computadora
- **Stack**: Python 3.11, OpenCV (MOG2), YOLOv8 ONNX Runtime, FastAPI, WebRTC / MJPEG.
- **Aspectos Destacados**:
  - Pipeline dual adaptativo: background subtraction de alta velocidad para detección de movimiento en reposo (1 FPS, ultra bajo consumo energético).
  - Escalamiento reactivo a 30 FPS con inferencia YOLOv8 al detectar perturbaciones de píxeles significativas.
  - Streaming de baja latencia vía FastAPI con bounding boxes vectoriales y clasificación de objetos en tiempo real.

### 2. Odoo WhatsApp Chatter Integration (Meta Cloud API)
- **Stack**: Odoo 16/17/18 ERP, Python, Meta Graph API v20+, PostgreSQL, Docker.
- **Aspectos Destacados**:
  - Integración bidireccional nativa en el chatter de Odoo para sincronización de mensajes, notas de voz, imágenes y plantillas HSM aprobadas por Meta.
  - Generación y despacho de facturas y reportes PDF directamente en memoria RAM (**0 bytes de consumo en disco**).
  - Verificación criptográfica HMAC-SHA256 de webhooks entrantes y arquitectura desacoplada para tolerancia a fallos de red.

### 3. WhatsBot Glam Nails (Bot Transaccional FSM)
- **Stack**: TypeScript, Node.js, Baileys / WhatsApp Web, PostgreSQL, Docker.
- **Aspectos Destacados**:
  - Máquina de Estados Finitos (FSM) determinista para agendamiento automatizado de citas y gestión de servicios estéticos.
  - Validación de reservas en tiempo real, conciliación de horarios concurrentes y notificaciones recordatorias automáticas.

## 💻 Instalación y Desarrollo Local

### Requisitos Previos
- **Node.js**: `v20.x` o superior
- **npm**: `v10.x` o superior

### Pasos de Ejecución

```bash
# 1. Clonar el repositorio
git clone https://github.com/jyersonrp/jyersonrp.github.io.git
cd jyersonrp.github.io

# 2. Instalar dependencias
npm install

# 3. Iniciar el entorno de desarrollo local
npm run dev

# 4. Ejecutar la suite de pruebas de seguridad
npm run test:security

# 5. Compilar para producción (Typecheck + Bundling optimizado)
npm run build

# 6. Previsualizar el build de producción
npm run preview
```
