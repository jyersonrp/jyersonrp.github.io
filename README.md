## 🚀 Características Principales

1. **Preloader Interactivo Estilo Milan Compain**:
   - Contador numérico progresivo `000%` a `100%` con barra glow y revelación fluida.
   - Opción para saltar la introducción en cualquier momento.

2. **Fondo de Constelación Estelar Interactivo ("Suivez l'étoile")**:
   - Canvas API puro de alto rendimiento con partículas estelares que reaccionan a la proximidad del cursor con física de atracción/repulsión y líneas de conexión luminiscentes.

3. **Bilingüe Español / Inglés en Tiempo Real**:
   - Selector instantáneo ES / EN que sincroniza títulos, descripciones de proyectos, experiencia laboral, métricas y modal de CV sin recargar la página. Persistencia en `localStorage`.

4. **Proyectos Estrella (Casos de Estudio Detallados)**:
   - **Sistema NVR con IA**: Pipeline híbrido OpenCV MOG2 + YOLOv8 ONNX, modo ECO adaptativo (1 FPS a 30 FPS) y streaming FastAPI.
   - **Odoo WhatsApp Chatter Meta**: Conexión con Meta Cloud API oficial, renderizado de facturas PDF en memoria RAM (0 bytes en disco) y seguridad HMAC-SHA256.
   - **WhatsBot Glam Nails**: Automatización transaccional de citas con TypeScript, Máquina de Estados Finitos (FSM) y PostgreSQL.

5. **Explorador Dinámico de Repositorios GitHub**:
   - Conexión en tiempo real con la API pública de GitHub (`@jyersonrp`).
   - Fallback offline integrado por si existe límite de tasa o fallo de red.
   - Búsqueda en vivo y filtrado por lenguaje de programación.

6. **Modal y Vista de CV Imprimible**:
   - Visualizador completo de currículum vitae con diseño optimizado para exportar o imprimir (`window.print()`).

7. **Conversión y Contacto Directo**:
   - Copiado de correo en 1 clic (`jyerson@gmail.com`) con confeti interactivo y feedback toast.
   - Enlace directo a WhatsApp (+58 416-1828027), LinkedIn y GitHub.
   - Reloj digital en vivo con la hora local de Maturín, Venezuela (`America/Caracas`).

## 🛠️ Tecnologías Utilizadas

- **Framework**: React 18 con TypeScript
- **Estilos**: Tailwind CSS con paleta personalizada `obsidian`, `emeraldNeon` y `cyanNeon`
- **Animaciones**: Framer Motion & HTML5 Canvas API
- **Iconografía**: Lucide React + Componentes SVG vectoriales dedicados
- **Efectos**: Canvas-Confetti
- **Bundler**: Vite 6

## 📦 Instalación y Ejecución Local

```bash
# 1. Clonar el repositorio o ingresar al directorio
cd d:/portafolio

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev

# 4. Construir para producción
npm run build

# 5. Vista previa del build de producción
npm run preview
```
